# Zoolivia

Piattaforma di gestione abbonamenti per il parco Zoolivia.

## Cancellazione abbonamento

Il file `cancellazione.html` contiene il flusso guidato per la cancellazione dell'abbonamento. Il processo si articola in 4 passaggi:

1. **Riepilogo** — L'utente visualizza il proprio piano attivo e i relativi vantaggi.
2. **Motivazione** — Viene richiesto il motivo della cancellazione per raccogliere feedback.
3. **Conferma** — Viene mostrato un riepilogo delle conseguenze e richiesta la conferma definitiva.
4. **Completamento** — L'utente riceve conferma della cancellazione e la data di fine servizio.

### Come aprire

Aprire il file `cancellazione.html` direttamente nel browser:

```bash
# macOS
open cancellazione.html

# Linux
xdg-open cancellazione.html

# Windows
start cancellazione.html
```

### Caratteristiche

- Interfaccia responsive (desktop e mobile)
- Flusso a step con indicatore di avanzamento
- Raccolta feedback sul motivo della cancellazione
- Possibilità di riattivare l'abbonamento
- Nessuna dipendenza esterna richiesta
