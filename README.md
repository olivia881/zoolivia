# ♻️ Promemoria Rifiuti

Una web app leggera e moderna per ricordarti ogni giorno quali rifiuti conferire.

## Funzionalità

- **Vista di oggi e domani** — vedi subito cosa devi buttare oggi e cosa è previsto per domani
- **Programma settimanale** — panoramica completa di tutta la settimana con evidenziazione del giorno corrente
- **Personalizzabile** — clicca su un giorno nella sezione "Personalizza" per scegliere i rifiuti di quel giorno
- **Salvataggio locale** — le impostazioni vengono salvate nel browser (localStorage), non serve un server
- **Responsive** — funziona bene su smartphone, tablet e desktop
- **Nessuna dipendenza** — solo HTML, CSS e JavaScript puro

## Come usare

1. Apri `index.html` nel browser
2. Nella sezione **Personalizza il Calendario**, clicca su un giorno per configurare i rifiuti da raccogliere
3. Le modifiche vengono salvate automaticamente nel browser
